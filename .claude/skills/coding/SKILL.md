## 编码规范
- 使用 Python3 开发，遵循 PEP8 代码风格（4 空格缩进、变量命名使用 snake_case）并添加必要注释和类型提示。
- 函数接口清晰，参数检查要完备，对可能的异常情况要有处理（必要时使用 try/except 并记录错误日志）。
- 日志使用统一格式（如 `logger.info("msg")`），不直接使用 `print` 输出；敏感信息不写入日志。
- 代码中不得硬编码配置值，需通过配置文件或环境变量传参；避免魔法数字/字符串，用常量或参数代替。
- 遵循项目风格：标识符、函数名和文件名保持一致性（参照CLAUDE.md编码条目），公共函数写Docstring说明功能。
